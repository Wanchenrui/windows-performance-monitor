# v0.7.0 稳定系统指标实现说明

## 进程与故障域

```text
NetworkInterface counters ─┐
PDH PhysicalDisk(_Total) ──┼─ independent Provider runners
GetSystemPowerStatus ──────┘        │
                                    ▼
                         atomic contract-v1 snapshot
                          ├─ latest-wins Desktop
                          ├─ bounded diagnostics
                          └─ bounded SQLite writer
```

三个 Provider 均以当前用户权限运行，不启动外部进程、不读取 WMI，也不
持有管理员令牌。任何一个 Provider 超时或异常只替换自身 group 的质量
状态；其余 Provider 的绝对期限不变。

## 数据语义

- `network`：活动非回环接口累计字节的每接口差分后求和，单位
  `byte_per_second`。首次、新接口和复位接口没有速率窗口。
- `diskIo`：所有物理磁盘 PDH `_Total` 的读写字节/操作速率，单位
  `byte_per_second` / `count_per_second`。首次采样未就绪。
- `power`：供电源、电池存在/充电/节能状态，以及已知时的电量和寿命。

Desktop 只读取这三个 group，不直接访问 PDH、网络 API 或电源 API。

## 资源与生命周期

网络基线最多与当前活动接口数同阶，为有界 RAM 状态；接口消失后在下一
采样被移除。电源 Provider 无跨样本状态。磁盘 Provider 只持有一个 PDH
query 与四个 counter handle；`ProviderScheduler.DisposeAsync` 在 runner
全部结束后统一释放。若不可取消的原生调用在停止等待 1 秒后仍未返回，
Scheduler 不并发销毁其句柄，而是在该调用完成后延迟释放；进程边界是最终
清理边界。

## 验证边界

纯逻辑测试固定累计计数与单调时间，验证：

- 两接口差分与求和；
- 计数器复位不产生负速率或尖峰；
- PDH 首样本为 `null`；
- 无电池不产生 0%/0 秒；
- 已知电池状态逐字段映射；
- Scheduler 释放状态型 Provider。

Windows Runner 另执行真实 Provider smoke、锁定恢复、产品发布、Desktop/
Agent/SQLite 生命周期烟测和加速资源门禁。
