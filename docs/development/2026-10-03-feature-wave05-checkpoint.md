## 本轮可用功能

- **本次运行的关注列表：**从 CPU 排行的 ☆ / ★ 或进程详情固定 / 取消关注，列表可快速切换，旧条目可一键取消。最多 12 条，仅当前 Desktop 运行保留；每条绑定 Agent 会话、PID 和创建时间，不按同名进程接续，不给关注额外采集或建立多条趋势。排行之外从完整已有快照匹配；缺席只能表示当前未观测到，不能确认已退出。旧会话、陈旧、断线和缺测读数不冒充实时数值。切换仍只记录选中后的新观测，沿用单实例 600 点 / 300 秒 / 64 KiB 上限。
- **刷新与图形布局：**排行、关注和质量组按固定身份复用按钮，原位更新读数与排序，避免每次刷新重建控件造成失焦；关注操作的可访问性名称包含进程名与 PID。打开抽屉时主趋势为其让出宽度，关闭后还原；紧凑视图保持原有尺寸。
- **自动尝试与具体帮助：**电源主查询异常 / 关键状态未知时补 Windows SystemBatteryState；GPU 负载缺测时补 Windows GPU Engine，失败后有界冷却。备用 GPU 仅聚合最忙引擎，不假冒物理显卡设备信息或温度；首次差分预热留空。Worker 启动失败计入既有每分钟 3 次预算，全局 Open 失败在预算内恢复，无目标传感器不无限重启。质量抽屉点选一组查看实际记录的路径、原因、建议与限制；只读快照，不在界面触发重试。缺组原因未知，无电池不需要修复，温度没有通用备用来源，也不保证更新驱动能读到。
