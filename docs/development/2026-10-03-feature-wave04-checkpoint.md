## 这轮增加了什么

- **诊断解释与建议：**在既有诊断抽屉点选一个事件，展开现象、依据、可能原因、建议和数据限制。只读事件及当前快照；缺测、陈旧和历史会话不会被解释成当前正常，建议不执行系统动作。
- **进程与趋势交互：**CPU 排行可点选实例，显示 PID、创建时间和当前内存；复用既有曲线显示选中后的 CPU 新观测。按 PID＋创建时间匹配，Agent 换实例需重选；缺测、断线、隐藏和不可读实例留空，不用 0 替代，不回填选中前历史。缓存限制为 600 点、300 秒、64 KiB。
- **可撤销轻量模式：**先探测 Agent 能力，再提供查询、开启和恢复入口。仅在当前 Agent 会话暂停 GPU / 温度请求，基础采集不变；恢复保存的原采集状态。已开始调用可继续，晚到结果不成为有效新观测。旧 Agent 不支持时不发模式请求；连接变化或操作未确认时要求刷新，不确认旧会话成功。不修改其他程序、系统设置或启动 Broker，不承诺量化收益。
